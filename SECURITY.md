# Security

Found a vulnerability? Please don't open a public issue.

1. Go to the **Security** tab of this repo
2. Click **Report a vulnerability**, add the version or commit and how to reproduce it

If that button isn't there, open an issue that only says you have a security report (no
details) and I'll reach out.

I check reports when I can. There's no fixed response time.

In scope: the code in this repo. Pingora, BoringSSL and other dependencies have their own
projects, report there.
